MODUL 01 / DATA ARCHITECTURE

Struktur Data

Struktur data adalah cara menyimpan dan mengatur data agar mudah diakses, diubah, dan diproses. Jelajahi tujuh struktur data berikut melalui visualisasi sederhana.

01 · Linear

Array

Array menyimpan beberapa data dalam satu kumpulan. Setiap elemen memiliki indeks; pada contoh ini indeks dimulai dari 0.

Klik elemen untuk melihat indeks dan nilainya.
02 · Linear berantai

Linked List

Linked list terdiri dari simpul (node). Setiap simpul menyimpan data dan tautan ke simpul berikutnya.

Panah menunjukkan tautan ke simpul berikutnya.
03 · Hierarki

Tree

Tree menyusun data bertingkat. Simpul paling atas disebut root; simpul di bawahnya disebut anak (child).

Contoh hubungan: A memiliki anak B dan C.
04 · Jaringan

Graph

Graph berisi simpul (vertex) yang dihubungkan oleh sisi (edge). Graph dapat menggambarkan jalan, pertemanan, atau jaringan komputer.

Pilih dua simpul lalu tekan Hubungkan untuk menambah sisi.
05 · FIFO

Queue (Antrean)

First In, First Out: data yang masuk pertama akan keluar pertama, seperti antrean di kantin.

Data masuk dari belakang dan keluar dari depan.
06 · LIFO

Stack (Tumpukan)

Last In, First Out: data terakhir masuk akan keluar pertama, seperti tumpukan piring.

Push menambah data, Pop mengambil data paling atas.
07 · Pencarian cepat

Hash Table

Hash table menggunakan fungsi hash untuk menentukan lokasi penyimpanan pasangan kunci dan nilai. Demo ini memakai huruf pertama sebagai kelompok sederhana, bukan hash kriptografi.

Masukkan kunci dan nilai, lalu tekan Simpan.

Bagian 2

Gerbang Logika dan Rangkaian Lampu

Gerbang logika memproses input digital 0 (OFF) dan 1 (ON). Hasilnya disebut output. Dalam simulasi ini, output 1 menyalakan LED, sedangkan output 0 mematikan LED.

Cara menggunakan: pilih gerbang, nyalakan/matikan sakelar A dan B, lalu perhatikan kabel yang menyala dan lampu output. Untuk NOT, hanya input A yang digunakan.

Pengaturan rangkaian

Input A: 0 (OFF)   Input B: 0 (OFF)
Gerbang: AND   Output: 0
A = 0 dan B = 0. Pada gerbang AND, kedua input harus bernilai 1 agar output menjadi 1.

Tabel kebenaran

Tabel berubah otomatis sesuai gerbang yang dipilih.

Penjelasan sederhana

Bagaimana menghubungkan rangkaian?

  1. Sumber input: sakelar A dan B menghasilkan nilai 0 atau 1.
  2. Kabel input: membawa nilai sakelar menuju kaki input gerbang. Kabel kuning bergerak saat nilai pada jalur bernilai 1.
  3. Gerbang logika: memproses nilai input sesuai aturan AND, OR, NOT, NAND, NOR, atau XOR.
  4. Kabel output: membawa hasil gerbang ke lampu LED.
  5. Lampu: menyala kuning saat output 1 dan mati saat output 0.

Catatan keselamatan: ini simulasi komputer, bukan petunjuk merangkai listrik rumah. Jangan menghubungkan percobaan siswa langsung ke listrik PLN.
