📖 1. Pengertian Tree

Tree atau pohon adalah struktur data yang digunakan untuk menyimpan data dalam hubungan hierarki atau bertingkat.

Contoh:
        A
       / \
      B   C
     / \   \
    D   E   F

📚 2. Istilah Penting

IstilahPengertian
NodeElemen atau data dalam Tree.
RootNode paling atas atau titik awal Tree.
ParentNode yang memiliki Child.
ChildNode yang berada di bawah Parent.
SiblingNode yang memiliki Parent yang sama.
LeafNode yang tidak memiliki Child.
EdgeHubungan/garis penghubung antar-Node.
LevelTingkat kedalaman sebuah Node dari Root.
HeightJarak maksimum dari Root menuju Leaf terdalam.

🌲 3. Binary Tree

Binary Tree adalah Tree yang setiap Node memiliki maksimal dua Child, yaitu Child kiri dan Child kanan.

          10
        /    \
       5      15
      / \    /  \
     2   7  12   20

🔎 4. Binary Search Tree (BST)

Pada BST berlaku aturan:

Nilai kiri < Parent < Nilai kanan

Contoh: pada Node 10, angka yang lebih kecil ditempatkan di kiri dan angka yang lebih besar di kanan.

🔄 5. Traversal

Traversal adalah proses mengunjungi Node pada Tree.

JenisUrutanContoh pada A-B-C
PreorderRoot → Left → RightA, B, C
InorderLeft → Root → RightB, A, C
PostorderLeft → Right → RootB, C, A

✏️ Latihan

Perhatikan Tree berikut:

              A
            /   \
           B     C
          / \   / \
         D   E F   G
  1. Siapa Root?
  2. Sebutkan semua Leaf.
  3. Siapa Parent dari D dan E?
  4. Siapa Sibling dari B?
  5. Sebutkan Child dari C.
  6. Berapa jumlah Node?
  7. Berapa jumlah Edge?
